## 2. Mã nguồn điều khiển máy bơm

Dưới đây là đoạn code Python sử dụng cảm biến độ ẩm để tự động bật/tắt máy bơm (`pump_status`):

```python
import RPi.GPIO as GPIO
import time

# Khai báo chân GPIO
SENSOR_PIN = 4
PUMP_PIN = 17

GPIO.setmode(GPIO.BCM)
GPIO.setup(SENSOR_PIN, GPIO.IN)
GPIO.setup(PUMP_PIN, GPIO.OUT)

def control_pump():
    try:
        while True:
            # Đọc giá trị từ cảm biến độ ẩm
            moisture_level = GPIO.input(SENSOR_PIN)
            pump_status = False
            
            if moisture_level == 0: # Đất khô
                GPIO.output(PUMP_PIN, GPIO.HIGH)
                pump_status = True
                print("Độ ẩm thấp: Đã BẬT máy bơm nước.")
            else: # Đất đủ ẩm
                GPIO.output(PUMP_PIN, GPIO.LOW)
                print("Độ ẩm ổn định: Đã TẮT máy bơm.")
                
            time.sleep(5)
    except KeyboardInterrupt:
        GPIO.cleanup()

if __name__ == "__main__":
    control_pump()
 ```
 ## 3. So sánh loại cảm biến (Cũ vs Mới)

|**Tiêu chí**|**Cảm biến loại cũ (Analog)**|**Cảm biến loại mới (Capacitive)**|
|-|-|-|
|**Độ bền**|Thấp (Dễ bị ăn mòn điện cực theo thời gian)|Cao (Lớp phủ chống ăn mòn tốt hơn)|
|**Độ chính xác**|Trung bình (Bị nhiễu bởi độ dẫn điện của đất)|Cao (Đo điện dung, ít bị ảnh hưởng bởi ion)|
|**Chi phí**|Rẻ|Nhỉnh hơn|
